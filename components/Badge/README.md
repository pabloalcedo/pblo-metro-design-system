# Badge

Etiqueta rectangular para el tipo, el sector o el estado («Relato», «Fintech», «En curso»). Cuadrada, 24px de alto, texto `label` a 13px.

- **El consumidor aporta**: el texto y opcionalmente `line`. `variant="filled"` usa el relleno de la línea con su `on-line-*`; `outline` usa borde `rule` fino y un punto de color.
- Usa `outline` para metadatos neutros (sector de un producto, género de un texto); `filled` solo cuando la etiqueta ES la línea.
- No hagas: badges redondeados, más de cuatro seguidos, badges como botones.
