# RouteTimeline

La trayectoria profesional como una línea de metro: una banda vertical de color (`stroke-route`) con una estación por etapa. La primera (la actual) es la terminal, rellena en `ink`; un cambio de rol importante es un transbordo, con estación más grande.

- **El consumidor aporta**: `stops` (de más reciente a más antigua) con `period`, `role`, `org`, `description` y `transfer`; `line` (por defecto `S`).
- La descripción es un logro concreto, no una lista de tareas.
- No hagas: más de seis estaciones (agrupa las antiguas), logos de empresas.
