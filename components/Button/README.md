# Button

Acción principal de una vista: módulo de 48px de alto (`space-12`), cuadrado, etiqueta `label` y flecha opcional.

- **El consumidor aporta**: `children` con verbo («Descargar CV», «Suscribirme»), `variant`, `href` si navega.
- `primary` (panel `sign`) una vez por vista; `secondary` (borde `stroke-rule`) para la alternativa; `quiet` para acciones de texto.
- Deshabilitado usa `line-grey` + `on-line-grey`, no opacidad.
- No hagas: botones redondeados, dos primarios juntos, etiquetas en mayúsculas o sin verbo.
