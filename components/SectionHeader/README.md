# SectionHeader

Cabecera de sección dentro de una página: regla `stroke-rule` arriba, título `h2` a la izquierda y `meta` a la derecha (cuántos hay, desde cuándo, de qué línea). Ordena la página en tramos, como los carteles entre andenes.

- **El consumidor aporta**: `title`, `meta` opcional, `id` para enlazar la sección y `line` si la sección es de una sola línea («Notas de producto» lleva N).
- Va al principio de cada sección dentro de `.ln-wrap.ln-section`; deja `space-8` hasta el contenido.
- No hagas: dos cabeceras seguidas, títulos de más de una línea, usarla como cabecera de página (para eso está `StationSign`).
