# Bullet

El disco de color con el glifo de una línea: identifica el tipo de contenido de un vistazo. Glifo en Archivo 700 sobre `line-*`, texto en su `on-line-*`.

- **El consumidor aporta**: `line` y, si el glifo difiere, `children`. Territorio Producto: `P` Productos, `X` Experimentos, `N` Notas de producto. Territorio Escritura: `E` Escritura. Además `S` Sobre mí y `A` Archivo. Dos caracteres se estrechan solos (`font-stretch`).
- Tamaños: `sm` 24px en filas y navegación, `md` 36px en tarjetas, `lg` 56px en cabeceras, `xl` 96px solo como gesto gráfico.
- `label=""` oculta el disco a los lectores de pantalla cuando el texto de al lado ya dice la línea (navegación).
- Haz: la misma línea para el mismo tipo de contenido en toda la web.
- No hagas: inventar glifos sueltos, usar el color sin glifo para algo que comunica, poner texto blanco sobre amarillo.
