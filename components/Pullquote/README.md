# Pullquote

Una idea destacada dentro de un ensayo o caso: `h2` en Archivo 700 bajo la barra `stroke-band`, con atribución en `meta`.

- **El consumidor aporta**: la frase (`children`), `cite` y opcionalmente `line`.
- Una por ensayo como máximo; la frase debe sostenerse sola.
- No hagas: comillas gigantes decorativas, citas de más de tres líneas.
