# TextArea

Campo de texto largo con el mismo trazo que `TextField`: cuadrado, borde `stroke-rule` en `rule` sobre `paper-raised`, etiqueta visible encima, 176px de alto mínimo y redimensionable en vertical.

- **El consumidor aporta**: `label`, `placeholder` (una pista de qué escribir, no la etiqueta), `rows`, `help` o `error`.
- Ocupa todo el ancho de su columna; no tiene ancho máximo propio.
- El error cambia el borde a `alert` y dice qué hacer.
