# SpecList

Lista de especificaciones a dos columnas: la etiqueta en `meta` a la izquierda y el contenido a la derecha, filas separadas por `hairline`. Es el formato del PRD dentro de la ficha de producto, y sirve para cualquier ficha técnica.

- **El consumidor aporta**: `items` con `label` y `value` (texto o lista de textos).
- En el PRD, siempre en este orden: Problema, Para quién, Objetivo y métrica, Dentro del alcance, Fuera del alcance, Requisitos clave, Riesgos. Se pueden añadir filas al final, no quitar.
- En móvil la etiqueta pasa encima del valor.
- No hagas: párrafos largos en una fila (máximo tres líneas o una lista corta), tablas dentro de una fila.
